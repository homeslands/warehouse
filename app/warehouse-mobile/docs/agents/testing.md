# Test

Đọc khi: viết/sửa test (jest setup, reanimated, fake-api, helper test header/tab/Stack).

- `jest.setup.ts` mock `expo-secure-store` toàn cục, nạp mock AsyncStorage chính thức và đặt sẵn API base URL.

- Reanimated trong jest theo docs testing: `resolver: 'react-native-reanimated/jest/resolver'` + `setUpTests()` (`jest.setup-after-env.ts`, kiểu matcher ở `jest.reanimated.d.ts`). Kiểm style đang animate bằng `toHaveAnimatedStyle` + `jest.useFakeTimers()`/`advanceTimersByTime`. `expo-haptics` được mock toàn cục trong `jest.setup.ts`. `react-native-gesture-handler`: `jest.setup.ts` nạp `react-native-gesture-handler/jestSetup` (docs RNGH; mock cả `src/` lẫn `lib/module/` — jest đọc `main` = `lib/module`, không cần `moduleNameMapper`); bước cài bindings UI runtime (`lib/module/handlers/gestures/installUIRuntimeBindings`) dùng bản `.web` no-op của RNGH (resolver Reanimated trỏ worklets sang bản web, `getUIRuntimeHolder` ném; đường dẫn nội bộ — RNGH dời file thì jest báo "Cannot find module"); `ReanimatedSwipeable` thay bằng khung tĩnh (vẽ `renderRightActions` + nội dung, `ref` no-op — cử chỉ không chạy trong jest) → test xoá dòng dùng thao tác a11y `delete` trên phần tử của `LineSummaryRow` (testID `export-line-<key>` / `import-line-<key>`). `jest.setup-after-env.ts` bỏ ĐÚNG câu cảnh báo "InputAccessoryView is deprecated" (đã chốt giữ ở Task 1) khỏi output. `expo-camera` cũng vậy: `CameraView` là View `testID="camera-view"` (quét = `fireEvent(view, 'barcodeScanned', { data })`), quyền điều khiển qua `jest.requireMock('expo-camera').__permission` (`current`, `afterRequest`, `request`, `reset()`).

- Test HTTP dùng adapter axios tự viết (xem `http.test.ts`, `src/shared/api/testing/fake-api.ts`); dùng lại mẫu này, không thêm thư viện mock mạng. Test phiếu nhập: import `fake-api` ĐẦU TIÊN, khai `route('get', '/warehouses/<kho>/import-forms/<slug>', () => ok(form))`, đếm ghi bằng `calls`/`callsTo`; dữ liệu mẫu ở `features/receive-checklist/model/fixtures.ts` (`makeForm`, `makeItem`, `makeLine`, `makeDraft`); đặt bản nháp trực tiếp bằng `useReceiveDraft.setState({ ctx, draft })` (trong `routing.test.tsx` bọc `await act(async () => …)` vì `SessionGate` đăng ký store này) và `reset()` + `stopDraftPersistence()` khi dọn.

- Header/tab native trong jest không có chữ: tiêu đề là prop của `RNSScreenStackHeaderConfig` (`title`, `largeTitle`), tab là `RNSTabsScreenIOS` (`title`, `tabBarItemTestID`), menu bên phải là prop `headerRightBarButtonItems` (bấm mục = sự kiện `pressHeaderBarButtonMenuItem` với `menuId`), ô tìm kiếm KHÔNG còn là `RNSSearchBar` (là `SearchField` trong danh sách: `fireEvent.changeText` lên ô theo nhãn placeholder; test chặn quay lại ô native ở `routing.test.tsx`), nút back của màn con là prop `backButtonDisplayMode` (native-stack chỉ gửi khi iOS ≥ 14 → test giả lập `Platform.Version`). Xem các helper trong `routing.test.tsx`. Tab đã mở vẫn nằm trong cây khi sang tab khác → tìm trong `tabScreen(<nhãn>)`, không tìm toàn màn. Test màn đơn lẻ: mock `expo-router` với `Stack.Screen` ghi lại `options` (xem `StockListScreen.test.tsx`). Test màn bước của form 3 bước trên Stack THẬT: `renderRouter(routes, { initialUrl, wrapper })` với màn giả (danh sách, màn xem) + màn bước thật, đọc Stack qua `getRouterState()` (mẫu `ExportReviewStepScreen.test.tsx`, `useWizardNav.test.tsx`); `renderRouter` tự bật `jest.useFakeTimers()` → chờ bằng `act(() => jest.runAllTimersAsync())`, KHÔNG chờ `setTimeout` thật (treo tới hết giờ); trả `jest.useRealTimers()` khi dọn. Nhiều màn bước cùng gắn → header của màn dưới cũng có trong cây: bấm nút header của màn TRÊN CÙNG bằng mục cuối (`findLast`).
- Form 3 bước là modal ở Stack gốc: test routing/Review dựng `modalStack(r)` (= `stackOf(r, 'import-form' | 'export-form')`) để assert Stack modal (vd `['[formSlug]/edit:px-1']`); test màn bước / hook bản nháp dùng `src/shared/lib/testing/wizard-nav.ts` (`reactNavigationWith` mock `useNavigationState` cho `atRoot`, `wizardNavWithLeaveSpies` ghi `exit/finish/finishToList/reopen` vào `leaveSpies`; đóng modal thật kiểm ở `useWizardNav.test.tsx` / `routing.test.tsx`).
