# D03 — Kiến trúc đích và ERD/API chủ

**APPROVED · WH-DEC-20261105-R2 · 05/11/2026**

Phê duyệt: Codex — Điều phối dự án, theo ủy quyền người dùng 05/11/2026; theo ủy quyền và làm rõ của người dùng. Không phải chữ ký người dùng hoặc review sản phẩm.

**Giữ kiến trúc đích trong ADR-001: React → REST Gateway → NestJS Storage Service qua gRPC → MySQL.**

Trước gói: W00, W02, W06, W10. Nguồn: D23 ADR-001 P8–P17, P235:P236; T231R7; D24 API T425:T446; D25:D27; code AppModule/routes

## Quy tắc

1. Gateway và Storage Service là hai process/service riêng; Gateway xác thực/ủy quyền biên và truyền identity/traceId đã xác minh, Storage Service kiểm lại quyền thao tác và scope. Không tin identity do client gRPC tự khai.
2. Các module danh mục, phiếu, lô, tồn và tài chính thuộc Storage Service. Ghi tồn/lô/phiếu/ledger dùng một transaction MySQL; không tách một nghiệp vụ tồn thành distributed transaction. File dùng provider riêng theo D06, sự kiện ra ngoài dùng outbox.
3. Nest app hiện tại là nguồn module tái sử dụng khi tách, không phải bằng chứng đã đạt microservices. Không phê duyệt monolith thay cho ADR. W02 phải có proto, service boundary, auth giữa services và migration path trước khi code.
4. D24 SDD + baseline bổ sung này là mô hình dữ liệu chuẩn; D26/D27 là diagram tham khảo, phải tái sinh từ schema đã đối chiếu, không chọn bản tên ngày làm chuẩn tự động.
5. UUID bất biến là ID nội bộ và ID API v1 theo SDD. Code chứng từ do server cấp và unique; slug phục vụ tra cứu/compatibility, không thay khóa. GET đọc, POST tạo/action, PUT thay thế đủ payload, PATCH sửa một phần có version; schema phân biệt omitted và null, không trộn semantics.
6. Estimate/lịch R0.2 giả định giữ monolith không còn đủ cơ sở để cam kết. Bắt buộc estimate lại phần tách Gateway/gRPC, chuyển UI D08 và các gói bị ảnh hưởng trước T0; không tự gán số ngày mới khi chưa breakdown.

## Căn cứ

Tuân thủ kiến trúc thiết kế gốc và giữ nguyên tính nguyên tử của nghiệp vụ tồn; không chọn thuận theo code hiện có.

## Ví dụ cần kiểm chứng

- Gateway không truy cập DB nghiệp vụ trực tiếp; gRPC từ caller không được cấp bị từ chối.
- Lỗi một dòng nhập làm rollback cả phiếu/lô/tồn/audit/outbox.
- PUT thiếu trường bắt buộc bị từ chối; PATCH omitted không xóa dữ liệu.
