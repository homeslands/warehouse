## Quy tắc

1. Baseline UI dùng Ant Design theo D08, tiếng Việt mặc định, desktop1440/tablet768/mobile390 và hỗ trợ320px. Form một cột trên mobile; dữ liệu quantity/action chính nhìn thấy hoặc có chế độ card/sticky có nhãn rõ.
2. Mỗi màn phải có screen/route/action map, field/validation/quyền/trạng thái, loading/empty/error/403/409/offline và success. W02–W03 phải nộp screen contracts trước implement FE; màn W04+ nộp theo gate miền.
3. API v1 phải có OpenAPI request/response/error/auth/scope/pagination/version và ví dụ; D29 A1=SP1 không là contract. Giữ HTTP status đúng, business error có code ổn định, traceId và field errors, không có stack/secret.
4. Ảnh fixture và UI code hiện tại chỉ là hiện trạng để nhận diện gap. Quyết định này duyệt chuẩn và bộ hồ sơ cần có, không tuyên bố mọi pixel/màn chưa thiết kế đã được ký. Setup/error-code docs là deliverable có owner trong W00/W11.
